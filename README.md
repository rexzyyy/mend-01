mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON text-editor calls to a tree of text files, finding the lines an edit names even when the model drifted whitespace or indentation, and applying every change atomically.

## Run it

```sh
node main.ts
```
